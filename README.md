# Music Dreamer 悦享音乐

Music Dreamer 是一个面向管理员、歌手和普通用户的前后端分离音乐平台课程项目。本仓库当前处于主体实施的 P0 基线阶段，尚未形成可运行应用。

## 已锁定方向

- Java 21、Spring Boot 3、Spring Cloud Alibaba、Nacos、Gateway、MySQL 和 Redis。
- 五个后端进程：Gateway、身份、音乐目录、互动和媒体服务。
- 两个 Vue 2.7 前端：用户音乐站与后台管理端。
- 真实会话、持久化、文件上传、Range 音频播放和三角色权限链路。
